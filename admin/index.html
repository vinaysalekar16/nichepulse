⚠️ Country data here is estimated from browser language settings — not 100% accurate. Google Analytics uses real IP geolocation for exact countries.

Step 1 — Add tracker.js to your site

Add this line inside <head> on every page to track views locally.

<script src="js/tracker.js"></script>

Add this to: index.html, blog.html, niche.html, about.html, contact.html

Step 2 — Google Analytics 4 (for real country + device data)

  1. Go to analytics.google.com → Create free account
  2. Create Property → choose Web → enter your site URL
  3. Copy your G-XXXXXXXX Measurement ID
  4. Paste the GA4 script into <head> of every page
  5. Wait 24 hours → visit Reports → Demographics for countries
  6. Connect AdSense to GA4 → see earnings in Monetisation report
💡 GA4 is completely free and gives you: real-time visitors, exact countries, device types, referral sources, session duration, bounce rate, and (with AdSense linked) revenue data.
